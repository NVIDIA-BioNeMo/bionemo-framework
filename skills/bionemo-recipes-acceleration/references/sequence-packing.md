# Sequence packing (THD)

Phase 4, Depths A and B only. Depth C cannot do this — THD attention requires a
`te.TransformerLayer`.

Packing removes padding waste. On variable-length biological sequences this is often a larger win
than FP8, and unlike FP8 it is numerically lossless — `test_golden_values_thd` in the shared harness
asserts BSHD and THD produce the same outputs.

## What THD means

- **BSHD** — `[batch, seq, heads, dim]`, the padded rectangle. Every sequence padded to
  `max_seq_length`.
- **THD** — `[total_tokens, heads, dim]`. Sequences concatenated end-to-end into a single row, with
  `cu_seqlens` (cumulative sequence-length offsets) telling the attention kernel where each
  sequence's boundaries are so it never attends across them.

## The canonical implementation

`$BIONEMO_RECIPES/models/esm2/collator.py` is the source of truth. Do not copy from any of its seven destinations —
they carry a `--- BEGIN COPIED FILE NOTICE ---` banner and are regenerated by
`$BIONEMO_RECIPES/ci/scripts/check_copied_files.py`. Vendor the source into the target repo.

Three components:

### `DataCollatorWithFlattening`

Wraps an inner collator (typically `DataCollatorForLanguageModeling`), flattens N variable-length
sequences into one `[1, total_tokens]` tensor, and emits:

- `cu_seq_lens_q`, `cu_seq_lens_k` — int32 cumulative offsets
- `max_length_q`, `max_length_k`

Two mutually exclusive padding modes:

- `pad_to_multiple_of` — appends one mock sequence to reach a fixed token count. Use for a
  consistent batch shape.

- `pad_sequences_to_be_divisible_by` — pads *each* sequence. **Required for context parallelism**,
  and helps FP8 GEMM alignment. This path calls TE's own helper:

  ```python
  from transformer_engine.pytorch.attention.dot_product_attention.context_parallel import (
      pad_thd_sequences_for_cp,
  )
  ```

  and additionally emits `cu_seq_lens_q_padded`, `cu_seq_lens_k_padded`, and
  `pad_between_seqs=True`.

### `TokenPackingDataset`

An `IterableDataset` that greedily accumulates samples up to `max_tokens_per_batch`, with
`drop_last`, `split_samples`, and padding-aware length rounding. It does the batching, which is why
the `DataLoader` gets `batch_size=None`.

### `create_thd_dataloader`

Model on `$BIONEMO_RECIPES/recipes/esm2_native_te/dataset.py::create_thd_dataloader`:

```python
if token_micro_batch_size is None:
    token_micro_batch_size = micro_batch_size * max_seq_length

data_collator = DataCollatorWithFlattening(
    collator=mlm_collator,
    pad_to_multiple_of=(
        token_micro_batch_size if pad_sequences_to_be_divisible_by is None else None
    ),
    pad_sequences_to_be_divisible_by=pad_sequences_to_be_divisible_by,
)

train_dataloader = dataloader_class(
    TokenPackingDataset(tokenized_dataset, max_tokens_per_batch=token_micro_batch_size),
    batch_size=None,  # TokenPackingDataset handles batching
    collate_fn=data_collator,
    num_workers=num_workers,
    pin_memory=not use_stateful_dataloader,
)
```

Constraint carried over from the reference: THD token packing requires a **streaming
(`IterableDataset`)** dataset. If the target uses a map-style dataset, either convert it with
`.to_iterable_dataset()` or report packing as not applied.

Keep the BSHD path alongside and select on a flag, as
`$BIONEMO_RECIPES/recipes/esm2_native_te/train_ddp.py` does:

```python
train_dataloader, dataset_or_sampler = (
    create_thd_dataloader(dist_config, **args.dataset)
    if args.use_sequence_packing
    else create_bshd_dataloader(dist_config, **args.dataset)
)
```

## Model-side wiring

Three changes, all in the encoder/decoder stack. Reference:
`$BIONEMO_RECIPES/models/esm2/modeling_esm_te.py::NVEsmEncoder.forward`.

1. **Set the format** — `config.attn_input_format = "thd"` when packing is on.

2. **Squeeze the batch dimension** before the first layer:

   ```python
   if (
       self.config.attn_input_format == "thd"
       and hidden_states.dim() == 3
       and hidden_states.size(0) == 1
   ):
       hidden_states = hidden_states.squeeze(0)
   ```

3. **Forward the cu_seqlens metadata into every TE layer**:

   ```python
   hidden_states = layer_module(
       hidden_states,
       attention_mask,
       rotary_pos_emb=te_rope_emb,
       cu_seqlens_q=kwargs.get("cu_seq_lens_q"),
       cu_seqlens_kv=kwargs.get("cu_seq_lens_k"),
       cu_seqlens_q_padded=kwargs.get("cu_seq_lens_q_padded"),
       cu_seqlens_kv_padded=kwargs.get("cu_seq_lens_k_padded"),
       max_seqlen_q=kwargs.get("max_length_q"),
       max_seqlen_kv=kwargs.get("max_length_k"),
       pad_between_seqs=kwargs.get("pad_between_seqs"),
   )
   ```

Dropping any of these silently produces attention that leaks across sequence boundaries — the model
still trains, the loss still falls, and the results are wrong. This is exactly what
`test_golden_values_thd` catches, which is why Tier 2 validation is not optional when packing is
applied.

## Context parallelism

Only if the target already uses CP. Set `pad_sequences_to_be_divisible_by = cp_size * 2` — see
`$BIONEMO_RECIPES/recipes/esm2_native_te/train_fsdp2_cp.py` — and use
`$BIONEMO_RECIPES/recipes/esm2_native_te/dataset.py::create_cp_dataloader`. The CP sharding utilities
(`DataCollatorForContextParallel`, `ContextParallelDataLoaderWrapper`, `_split_batch_by_cp_rank`)
are in the same `$BIONEMO_RECIPES/models/esm2/collator.py`. Background: `$BIONEMO_RECIPES/recipes/context_parallel.md`.

## Hardware caveat

`fused_attn` THD is xfail'd on sm_80 (A100) and sm_120 (RTX 50xx) in
`$BIONEMO_RECIPES/models/esm2/tests/common/test_modeling_common.py`. Packing still works there through
`flash_attn`. Note it in the report; do not block on it.

## Measuring the win

The GEMM benchmark says nothing about packing — attention is precision-agnostic and packing changes
token count, not GEMM shape. Get the number from the vendored `PerfLogger`: compare
`train/tokens_per_second_per_gpu` against
`train/unpadded_tokens_per_second_per_gpu`. The gap between them on the unpacked baseline *is* the
padding waste that packing recovers.
